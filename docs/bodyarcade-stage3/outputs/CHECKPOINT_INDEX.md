# BodyArcade Shared-World — Checkpoint Index

Ordered execution sequence. One checkpoint per implementation session; every checkpoint ends with a live local demo (or, for 03, an explicit decision gate) and the mandatory stop for user review. Approval of a checkpoint never authorizes starting the next. Splits 04A/04B and 14A/14B/14C are the two research-justified adjustments to the master context §13.2 ladder, recorded with their causes in the Implementation Master §9.
